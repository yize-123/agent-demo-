## 1. 项目概述与准备工作

### 1.1 我们要构建什么？

我们将构建一个完整的 **AI Agent** 系统，具备以下能力：

- 🔄 **ReAct 框架**：推理-行动循环，智能判断何时调用工具
- 📚 **RAG 检索增强生成**：从知识库中检索相关信息
- 👥 **MCP 多智能体协作**：多个专业智能体协同工作
- 🔧 **工具调用**：支持多种实用工具（搜索、文件、待办、计算等）

### 1.3 学习顺序（重要）

```
为什么是这个顺序？

因为后面的代码依赖前面的代码！

pom.xml（定义项目依赖）
        ↓
配置文件 + 启动类
        ↓
Model 层（数据结构）← 不依赖任何其他层
        ↓
Tools 层（工具实现）← 依赖 Model 层
        ↓
Service 层（服务）← 依赖 Model 和 Tools 层
        ↓
Agent 层（核心逻辑）← 依赖 Service 层
        ↓
Controller 层（API）← 依赖 Agent 层
        ↓
前端页面 ← 依赖 Controller 层
```

### 1.2 pom.xml

**为什么要先写 pom.xml？**

因为 pom.xml 是项目的"地基"，它告诉 Maven：
- 项目用什么版本的 Java
- 需要下载哪些依赖库
- 如何构建和运行项目

```xml
  这是整个项目的"地基"，Maven 通过这个文件知道如何构建和运行项目
-->
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
```

### 2.1 Message.java

```java
/**
 * 消息模型类
 * 
 * 用于表示对话中的一条消息，是构建对话历史的基本单元
 * 
 * 消息类型（role字段）：
 * - user：用户发送的消息
 * - assistant：AI助手回复的消息
 * - tool：工具执行结果的消息
 * - system：系统提示消息（指导AI行为）
 */
package com.example.aigent.model;  

// 导入 JSON 属性注解，用于自定义 JSON 序列化时的字段名
import com.fasterxml.jackson.annotation.JsonProperty;  

// Lombok 注解：自动生成全参构造函数
import lombok.AllArgsConstructor;  

// Lombok 注解：启用 Builder 模式，方便链式调用创建对象
import lombok.Builder;  

// Lombok 注解：自动生成 getter、setter、toString、equals、hashCode 方法
import lombok.Data;  

// Lombok 注解：自动生成无参构造函数
import lombok.NoArgsConstructor;  

/**
 * 消息类
 * 
 * 使用 Lombok 注解后，不需要手动编写：
 * - getter/setter 方法
 * - 构造函数
 * - toString() 方法
 * - equals() 和 hashCode() 方法
 */
@Data  
@Builder  
@NoArgsConstructor  
@AllArgsConstructor  
public class Message {  
    
    /**
     * 消息角色
     * 可选值：user（用户）、assistant（助手）、tool（工具）、system（系统）
     */
    private String role;  
    
    /**
     * 消息内容
     * 实际的文本内容，如用户提问、助手回答、工具返回结果等
     */
    private String content;  
    
    /**
     * 工具名称（仅 tool 角色使用）
     * 当消息是工具执行结果时，记录调用的工具名称
     * 
     * @JsonProperty("name") 表示 JSON 序列化时使用 "name" 作为字段名
     */
    @JsonProperty("name")  
    private String toolName;  
    
    /**
     * 工具调用ID（用于关联工具调用和工具返回）
     * 每次工具调用都会生成一个唯一ID，工具返回时携带此ID
     * 这样可以正确关联调用和返回
     * 
     * @JsonProperty("tool_call_id") 表示 JSON 序列化时使用 "tool_call_id" 作为字段名
     */
    @JsonProperty("tool_call_id")  
    private String toolCallId;  
    
    /**
     * 创建用户消息的便捷方法
     * 
     * @param content 用户输入的内容
     * @return 构建好的用户消息对象
     */
    public static Message user(String content) {  
        return Message.builder().role("user").content(content).build();
    }
    
    /**
     * 创建助手消息的便捷方法
     * 
     * @param content 助手回复的内容
     * @return 构建好的助手消息对象
     */
    public static Message assistant(String content) {  
        return Message.builder().role("assistant").content(content).build();
    }
    
    /**
     * 创建工具消息的便捷方法
     * 
     * @param toolName 工具名称
     * @param content 工具执行结果
     * @param toolCallId 工具调用ID（用于关联）
     * @return 构建好的工具消息对象
     */
    public static Message tool(String toolName, String content, String toolCallId) {  
        return Message.builder()
                .role("tool")
                .toolName(toolName)
                .content(content)
                .toolCallId(toolCallId)
                .build();
    }
    
    /**
     * 创建系统消息的便捷方法
     * 
     * @param content 系统提示内容
     * @return 构建好的系统消息对象
     */
    public static Message system(String content) {  
        return Message.builder().role("system").content(content).build();
    }
}
```

### 2.2 Tool.java

```java
/**
 * 工具接口
 * 
 * 所有工具必须实现此接口，定义了工具的基本行为
 * 
 * 为什么使用接口？
 * - 统一所有工具的行为规范
 * - 便于工具注册和管理
 * - 实现多态，让 Agent 可以统一调用不同工具
 */
package com.example.aigent.model;  

// 导入 JSON 节点类，用于表示 JSON 数据
import com.fasterxml.jackson.databind.JsonNode;  

// 导入 JSON 对象映射器，用于创建和操作 JSON
import com.fasterxml.jackson.databind.ObjectMapper;  

// 导入 JSON 数组节点
import com.fasterxml.jackson.databind.node.ArrayNode;  

// 导入 JSON 对象节点
import com.fasterxml.jackson.databind.node.ObjectNode;  

/**
 * 工具接口
 * 
 * 定义了工具必须实现的四个核心方法：
 * 1. getName() - 获取工具名称
 * 2. getDescription() - 获取工具描述
 * 3. getParameters() - 获取参数定义
 * 4. execute() - 执行工具
 */
public interface Tool {  
    
    /**
     * 获取工具名称
     * 
     * @return 工具名称（如 "web_search", "read_file"）
     */
    String getName();  
    
    /**
     * 获取工具描述
     * 
     * 描述应该清晰说明工具的用途和使用场景，
     * LLM 会根据这个描述决定是否调用该工具
     * 
     * @return 工具描述文本
     */
    String getDescription();  
    
    /**
     * 获取工具参数的 JSON Schema 定义
     * 
     * JSON Schema 是一种用于描述 JSON 数据结构的格式，
     * LLM 需要知道工具接受什么参数
     * 
     * @return 参数的 JSON Schema（JsonNode 格式）
     */
    JsonNode getParameters();  
    
    /**
     * 执行工具
     * 
     * @param arguments 工具参数（JSON 格式）
     * @return 工具执行结果（JSON 字符串格式）
     */
    String execute(JsonNode arguments);  
    
    /**
     * 默认方法：转换为 OpenAI 工具格式
     * 
     * OpenAI API 要求工具必须是特定的 JSON 格式，
     * 这个方法自动将工具转换为符合要求的格式
     * 
     * @param mapper ObjectMapper 实例
     * @return OpenAI 格式的工具定义
     */
    default ObjectNode toOpenAITool(ObjectMapper mapper) {  
        // 创建工具对象
        ObjectNode toolObject = mapper.createObjectNode();  
        // 设置类型为 function（OpenAI 要求）
        toolObject.put("type", "function");  
        
        // 创建函数对象
        ObjectNode functionObject = mapper.createObjectNode();  
        functionObject.put("name", getName());        // 设置函数名称
        functionObject.put("description", getDescription());  // 设置函数描述
        functionObject.set("parameters", getParameters());    // 设置参数定义
        
        // 将函数对象放入工具对象
        toolObject.set("function", functionObject);  
        return toolObject;  // 返回格式化后的工具对象
    }
    
    /**
     * 静态方法：创建参数定义
     * 
     * 辅助方法，帮助工具实现类快速构建参数的 JSON Schema
     * 
     * @param mapper ObjectMapper 实例
     * @param properties 参数属性定义
     * @param required 必填字段列表
     * @return 参数的 JSON Schema
     */
    static ObjectNode createParameters(ObjectMapper mapper, ObjectNode properties, String... required) {  
        // 创建参数对象
        ObjectNode params = mapper.createObjectNode();  
        // 设置类型为 object
        params.put("type", "object");  
        // 设置属性定义
        params.set("properties", properties);  
        
        // 创建必填字段数组
        ArrayNode requiredArray = mapper.createArrayNode();  
        for (String field : required) {  // 遍历必填字段
            requiredArray.add(field);    // 添加到数组
        }
        // 设置必填字段
        params.set("required", requiredArray);  
        
        return params;  // 返回参数定义
    }
}
```

### 2.3 ToolCall.java

```java
/**
 * 工具调用模型类
 * 
 * 封装 LLM 返回的工具调用信息，用于解析和执行工具调用
 * 
 * 当 LLM 决定调用工具时，会返回一个工具调用对象，
 * 这个类负责解析和封装这些信息
 */
package com.example.aigent.model;  

// Lombok 注解：自动生成全参构造函数
import lombok.AllArgsConstructor;  

// Lombok 注解：启用 Builder 模式
import lombok.Builder;  

// Lombok 注解：自动生成 getter/setter 等方法
import lombok.Data;  

// Lombok 注解：自动生成无参构造函数
import lombok.NoArgsConstructor;  

/**
 * 工具调用类
 * 
 * 包含工具调用所需的所有信息：
 * - id：工具调用ID（用于关联调用和返回）
 * - name：工具名称
 * - arguments：工具参数
 */
@Data  
@Builder  
@NoArgsConstructor  
@AllArgsConstructor  
public class ToolCall {  
    
    /**
     * 工具调用ID
     * 
     * 每次工具调用都会生成一个唯一ID，工具返回结果时会携带此ID，
     * 用于正确关联调用和返回结果
     */
    private String id;  
    
    /**
     * 工具名称
     * 
     * 要调用的工具名称，如 "web_search"、"read_file" 等
     */
    private String name;  
    
    /**
     * 工具参数（JSON格式字符串）
     * 
     * 传递给工具的参数，以 JSON 字符串形式存储
     */
    private String arguments;  
    
    /**
     * 获取工具名称的便捷方法
     * 
     * @return 工具名称
     */
    public String getToolName() {  
        return name;
    }
    
    /**
     * 判断工具调用是否有效
     * 
     * 有效条件：
     * 1. 工具名称不为空
```

```java
        ObjectNode params = objectMapper.createObjectNode();  
        params.put("type", "object");  
        
        ObjectNode properties = objectMapper.createObjectNode();  
        
        // file_path 参数（必填）
        ObjectNode pathParam = objectMapper.createObjectNode();  
        pathParam.put("type", "string");  
        pathParam.put("description", "要读取的文件路径");  
        properties.set("file_path", pathParam);  
        
        // max_lines 参数（可选）
        ObjectNode maxLinesParam = objectMapper.createObjectNode();  
        maxLinesParam.put("type", "integer");  
        maxLinesParam.put("description", "最大读取行数，默认100");  
        properties.set("max_lines", maxLinesParam);  
        
        params.set("properties", properties);  
        params.putArray("required").add("file_path");  // file_path 是必填字段
        
        return params;  
    }

    /**
     * 执行工具
     * 
     * @param arguments 工具参数
     * @return 执行结果（JSON 字符串）
     */
    @Override
    public String execute(JsonNode arguments) {  
        try {
            // Step 1: 获取参数
            String filePath = arguments.get("file_path").asText();  // 文件路径（必填）
            int maxLines = arguments.has("max_lines")  // 最大行数（可选，默认100）
                    ? arguments.get("max_lines").asInt() : 100;

            // Step 2: 转换为 Path 对象
            Path path = Paths.get(filePath);  
            
            // Step 3: 验证文件
            if (!Files.exists(path)) {  // 检查文件是否存在
                return "{\"error\": \"文件不存在: " + filePath + "\"}";
            }
            
            if (!Files.isRegularFile(path)) {  // 检查是否为普通文件
                return "{\"error\": \"不是普通文件: " + filePath + "\"}";
            }

            // Step 4: 读取文件内容
            String content = Files.readString(path);  
            
            // Step 5: 按行分割并截取
            String[] lines = content.split("\n");  
            int actualLines = Math.min(lines.length, maxLines);  // 实际读取的行数
            StringBuilder result = new StringBuilder();
            for (int i = 0; i < actualLines; i++) {  
                result.append(lines[i]).append("\n");
            }
            
            // Step 6: 判断是否被截断
            boolean truncated = lines.length > maxLines;  

            // Step 7: 构建 JSON 结果
            return "{\"file\": \"" + filePath + "\", " +
                   "\"total_lines\": " + lines.length + ", " +
                   "\"read_lines\": " + actualLines + ", " +
                   "\"truncated\": " + truncated + ", " +
                   "\"content\": \"" + escapeJson(result.toString()) + "\"}";
                   
        } catch (IOException e) {  // 捕获 IO 异常
            log.error("读取文件失败", e);  
            return "{\"error\": \"读取文件失败: " + e.getMessage() + "\"}";  
        }
    }
    
    /**

     * 
     * @param text 原始文本
     * @return 转义后的文本
     */
    private String escapeJson(String text) {  
        return text.replace("\\", "\\\\")  // 转义反斜杠
                   .replace("\"", "\\\"")  // 转义双引号
                   .replace("\n", "\\n")   // 转义换行符
                   .replace("\r", "\\r");  // 转义回车符
    }
```

```java
// 导入原子整数类（线程安全的计数器）
import java.util.concurrent.atomic.AtomicInteger;  

/**
 * 待办事项管理工具实现类
 * 
 * 使用线程安全的数据结构存储待办事项，确保并发访问安全
 */
@Slf4j  
@Component  
public class TodoManagerTool implements Tool {

     * JSON 对象映射器

     * 用于生成参数定义和序列化结果

    /**
     * 待办事项存储（线程安全）

     * 使用 ConcurrentHashMap 确保多线程环境下的数据安全
     * 键：任务ID，值：待办事项对象
     */
    private final ConcurrentMap<Integer, TodoItem> todoStore = new ConcurrentHashMap<>();  
    
    /**
     * ID计数器（线程安全）
     * 
     * 使用 AtomicInteger 确保多线程环境下ID的唯一性
     */
    private final AtomicInteger idCounter = new AtomicInteger(1);  

    /**
     * 构造函数
     *

    /**
     * 获取工具名称
     * 
     * @return 工具名称
     */
    @Override
    public String getName() {  
        return "manage_todo";
    }

    /**
     * 获取工具描述
     * 
     * @return 工具描述
     */
    @Override
    public String getDescription() {  
        return "管理待办事项。参数：action（操作类型：add/delete/list/complete），task（任务内容，add时必填），id（任务ID，delete/complete时必填）";

    /**
     * 获取工具参数的 JSON Schema 定义
     * 
     * @return 参数的 JSON Schema

        // action 参数（操作类型）
        ObjectNode actionProp = objectMapper.createObjectNode();  
        actionProp.put("type", "string");  
        actionProp.put("description", "操作类型：add/delete/list/complete");  
        properties.set("action", actionProp);  
        
        // task 参数（任务内容）
        ObjectNode taskProp = objectMapper.createObjectNode();  
        taskProp.put("type", "string");  
        taskProp.put("description", "任务内容");  
        properties.set("task", taskProp);  
        
        // id 参数（任务ID）
        ObjectNode idProp = objectMapper.createObjectNode();  
        idProp.put("type", "integer");  
        idProp.put("description", "任务ID");  
        properties.set("id", idProp);  
        
        // 创建参数对象
        ObjectNode params = objectMapper.createObjectNode();  
        params.put("type", "object");  
        params.set("properties", properties);  
        
        return params;

    /**
     * 执行工具
     * 
     * @param arguments 工具参数（JSON 格式）
     * @return 执行结果（JSON 字符串）
     */
    @Override
    public String execute(JsonNode arguments) {  
        // Step 1: 获取操作类型参数
        String action = arguments.has("action") ? arguments.get("action").asText() : "";  
        
        // Step 2: 根据操作类型分发处理
        return switch (action.toLowerCase()) {  
            case "add" -> addTodo(arguments);        // 添加待办
            case "delete" -> deleteTodo(arguments);  // 删除待办
            case "list" -> listTodos();              // 列出待办
            case "complete" -> completeTodo(arguments);  // 完成待办
            default -> "{\"error\": \"未知操作: " + action + "\"}";  // 未知操作
        };
    }

    /**
     * 添加待办事项
     * 
     * @param arguments 工具参数，包含 task（任务内容）
     * @return 执行结果（JSON 字符串）
     */
    private String addTodo(JsonNode arguments) {  
        // Step 1: 获取任务内容
        String task = arguments.has("task") ? arguments.get("task").asText() : "";  
        
        // Step 2: 验证任务内容
        if (task.isEmpty()) {  
            return "{\"error\": \"任务内容不能为空\"}";
        }
        
        // Step 3: 生成唯一ID并存储
        int id = idCounter.getAndIncrement();  // 获取下一个ID（原子操作）
        todoStore.put(id, new TodoItem(id, task, false));  // 存储待办事项
        
        // Step 4: 返回成功结果
        return "{\"status\": \"success\", \"message\": \"添加成功\", \"id\": " + id + "}";  
    }

    /**
     * 删除待办事项
     * 
     * @param arguments 工具参数，包含 id（任务ID）
     * @return 执行结果（JSON 字符串）
     */
    private String deleteTodo(JsonNode arguments) {  
        // Step 1: 获取任务ID
        int id = arguments.has("id") ? arguments.get("id").asInt() : -1;  
        
        // Step 2: 验证ID有效性
        if (id <= 0) {  
            return "{\"error\": \"无效的任务ID\"}";
        }
        
        // Step 3: 删除任务
        if (todoStore.remove(id) != null) {  
            return "{\"status\": \"success\", \"message\": \"删除成功\"}";  
        } else {
            return "{\"error\": \"任务不存在\"}";  
        }
    }

    /**
     * 列出所有待办事项
     * 
     * @return 待办事项列表（JSON 字符串）
     */
    private String listTodos() {  
        // Step 1: 获取所有待办事项并排序
        List<TodoItem> items = new ArrayList<>(todoStore.values());  
        items.sort((a, b) -> Integer.compare(a.id, b.id));  // 按ID升序排序
        
        // Step 2: 构建结果对象
        ObjectNode result = objectMapper.createObjectNode();  
        result.put("total", items.size());  // 设置总数
        
        // Step 3: 创建待办数组
        ArrayNode todosArray = objectMapper.createArrayNode();  
        items.forEach(item -> {  
            ObjectNode todo = objectMapper.createObjectNode();  
            todo.put("id", item.id);          // 设置ID
            todo.put("task", item.task);      // 设置任务内容
            todo.put("completed", item.completed);  // 设置完成状态
            todosArray.add(todo);  
        });
        result.set("todos", todosArray);  
        
        // Step 4: 序列化为JSON字符串
        try {
            return objectMapper.writeValueAsString(result);  
        } catch (Exception e) {  
            log.error("序列化失败: {}", e.getMessage());  
            return "{\"error\": \"序列化失败\"}";  
        }
    }

    /**
     * 标记待办事项为完成
     * 
     * @param arguments 工具参数，包含 id（任务ID）
     * @return 执行结果（JSON 字符串）
     */
    private String completeTodo(JsonNode arguments) {  
        // Step 1: 获取任务ID
        int id = arguments.has("id") ? arguments.get("id").asInt() : -1;  
        
        // Step 2: 验证ID有效性
        if (id <= 0) {  
            return "{\"error\": \"无效的任务ID\"}";
        }
        
        // Step 3: 获取待办事项
        TodoItem item = todoStore.get(id);  
        if (item == null) {  
            return "{\"error\": \"任务不存在\"}";
        }
        
        // Step 4: 标记为完成
        item.completed = true;  
        return "{\"status\": \"success\", \"message\": \"已标记完成\"}";  
    }
    
    /**
     * 内部类：待办事项
     * 
     * 用于存储单个待办事项的信息
     */
    private static class TodoItem {  
        int id;          // 任务ID
        String task;     // 任务内容
        boolean completed;  // 完成状态
        
        /**
         * 构造函数
         * 
         * @param id 任务ID
         * @param task 任务内容
         * @param completed 完成状态
         */
        TodoItem(int id, String task, boolean completed) {  
            this.id = id;
            this.task = task;
            this.completed = completed;
        }
    }
}
```

```java
// 导入 Tool 接口
import com.example.aigent.model.Tool;  

// 导入 JSON 节点类

// 导入 BigDecimal 类，用于精确计算（避免浮点数精度问题）
import java.math.BigDecimal;  

// 导入舍入模式枚举
import java.math.RoundingMode;  

/**
 * 计算器工具实现类
 * 
 * 使用 BigDecimal 进行精确计算，避免浮点数精度问题
 */
@Slf4j  
@Component  
public class CalculatorTool implements Tool {  

    private final ObjectMapper objectMapper;  

    /**
     * 构造函数
     * 
     * @param objectMapper JSON 对象映射器
     */

    }

    @Override
    public String getName() {  
        return "calculator";
    }

    @Override
    public String getDescription() {  
        return "执行数学计算。支持：add(加)、subtract(减)、multiply(乘)、divide(除)、power(幂)、sqrt(平方根)";
    }

    @Override
    public JsonNode getParameters() {  
        ObjectNode params = objectMapper.createObjectNode();  
        params.put("type", "object");  
        
        ObjectNode properties = objectMapper.createObjectNode();  
        
        // operation 参数（操作类型，必填）
        ObjectNode operationParam = objectMapper.createObjectNode();  
        operationParam.put("type", "string");  
        operationParam.put("description", "操作：add、subtract、multiply、divide、power、sqrt");  
        properties.set("operation", operationParam);  
        
        // num1 参数（第一个数，必填）
        ObjectNode num1Param = objectMapper.createObjectNode();  
        num1Param.put("type", "number");  
        num1Param.put("description", "第一个数");  
        properties.set("num1", num1Param);  
        
        // num2 参数（第二个数，可选）
        ObjectNode num2Param = objectMapper.createObjectNode();  
        num2Param.put("type", "number");  
        num2Param.put("description", "第二个数");  
        properties.set("num2", num2Param);  
        
        params.set("properties", properties);  
        params.putArray("required").add("operation").add("num1");  // 必填字段
        
        return params;  
    }

    /**
     * 执行工具
     * 
     * @param arguments 工具参数（JSON 格式）
     * @return 执行结果（JSON 字符串）
     */
    @Override
    public String execute(JsonNode arguments) {  
        try {
            // Step 1: 获取参数
            String operation = arguments.get("operation").asText().toLowerCase();  // 操作类型
            BigDecimal num1 = BigDecimal.valueOf(arguments.get("num1").asDouble());  // 第一个数
            BigDecimal num2 = arguments.has("num2")  // 第二个数（可选）
                    ? BigDecimal.valueOf(arguments.get("num2").asDouble()) : null;
            
            // Step 2: 根据操作类型执行计算
            BigDecimal result;  
            switch (operation) {  
                case "add":  // 加法
                    result = num1.add(num2 != null ? num2 : BigDecimal.ZERO);  
                    break;
                case "subtract":  // 减法
                    result = num1.subtract(num2 != null ? num2 : BigDecimal.ZERO);  
                    break;
                case "multiply":  // 乘法
                    result = num1.multiply(num2 != null ? num2 : BigDecimal.ONE);  
                    break;
                case "divide":  // 除法
                    // 检查除数是否为零
                    if (num2 == null || num2.compareTo(BigDecimal.ZERO) == 0) {  
                        return "{\"error\": \"除数不能为零\"}";
                    }
                    // 保留10位小数，四舍五入
                    result = num1.divide(num2, 10, RoundingMode.HALF_UP);  
                    break;
                case "power":  // 幂运算
                    // 幂运算需要第二个参数
                    if (num2 == null) {  
                        return "{\"error\": \"幂运算需要第二个参数\"}";
                    }
                    result = num1.pow(num2.intValue());  
                    break;
                case "sqrt":  // 平方根
                    // 不能对负数取平方根
                    if (num1.compareTo(BigDecimal.ZERO) < 0) {  
                        return "{\"error\": \"不能对负数取平方根\"}";
                    }
                    result = BigDecimal.valueOf(Math.sqrt(num1.doubleValue()));  
                    break;
                default:  // 未知操作
                    return "{\"error\": \"未知操作: " + operation + "\"}";
            }
            
            // Step 3: 构建 JSON 结果
            return "{\"operation\": \"" + operation + "\", \"num1\": " + num1 + 
                   (num2 != null ? ", \"num2\": " + num2 : "") + 
                   ", \"result\": " + result + "}";
                   
        } catch (Exception e) {  
            log.error("计算失败", e);  
            return "{\"error\": \"计算失败: " + e.getMessage() + "\"}";  
        }
    }
}
```

```java
     * @return 搜索结果（JSON 字符串）
     */
    private String executeRealSearch(String query) {  
        try {
            // Step 1: 构建请求体
            String jsonBody = "{\"query\": \"" + query + "\", \"search_depth\": \"basic\"}";
            
            // Step 2: 创建 HTTP 请求
            HttpRequest request = HttpRequest.newBuilder()
                    .uri(URI.create("https://api.tavily.com/search"))  // API 地址
                    .header("Content-Type", "application/json")         // 设置内容类型
                    .header("Authorization", "Bearer " + tavilyApiKey)  // 设置认证头
                    .POST(HttpRequest.BodyPublishers.ofString(jsonBody))  // POST 请求
                    .build();

            // Step 3: 发送请求并获取响应
            HttpResponse<String> response = httpClient.send(request, 
                    HttpResponse.BodyHandlers.ofString());
            
            // Step 4: 处理响应
            if (response.statusCode() == 200) {  // 成功
                return response.body();  
            } else {  // 失败
                return "{\"error\": \"搜索失败: " + response.statusCode() + "\"}";  
            }
            
        } catch (Exception e) {  // 捕获所有异常
            log.error("搜索失败", e);  
            return "{\"error\": \"搜索失败: " + e.getMessage() + "\"}";  
        }
    }
```

```java
package com.example.aigent.service;
```

```java
@Slf4j  
@Service  
public class OpenAIService {

     */
    public String chatCompletion(List<Message> messages) throws Exception {

        ObjectNode requestBody = objectMapper.createObjectNode();  
        requestBody.put("model", model);        // 设置模型
        requestBody.put("temperature", temperature);  // 设置温度
        requestBody.put("tool_choice", "auto"); // 让 AI 自动决定是否调用工具
        
        // Step 2: 构建消息数组（特殊处理工具消息）
        ArrayNode messagesArray = objectMapper.createArrayNode();  
        for (Message message : messages) {  
            ObjectNode msgNode = objectMapper.createObjectNode();  
            msgNode.put("role", message.getRole());    // 设置角色
            msgNode.put("content", message.getContent());  // 设置内容
            
            // 处理工具返回消息（需要包含工具名称和调用ID）
            if ("tool".equals(message.getRole()) && message.getToolName() != null) {
                msgNode.put("name", message.getToolName());  // 设置工具名称
                if (message.getToolCallId() != null) {
                    msgNode.put("tool_call_id", message.getToolCallId());  // 设置工具调用ID
                }
            }
            
            messagesArray.add(msgNode);  
        }
        requestBody.set("messages", messagesArray);  
        requestBody.set("tools", tools);  // 设置可用工具
        
        // Step 3: 发送请求并提取工具调用
        String response = sendRequest(requestBody);  
        return extractToolCall(response);  
    }

     * 发送 HTTP 请求到 OpenAI

     * @return API 响应体（JSON 字符串）

                .POST(HttpRequest.BodyPublishers.ofString(jsonBody))  // POST 请求
                .build();
        
        log.debug("发送请求到OpenAI: {}", jsonBody);  
        
        // Step 3: 发送请求并获取响应
        HttpResponse<String> response = httpClient.send(request, 
                HttpResponse.BodyHandlers.ofString());
        
        log.debug("OpenAI响应: {}", response.body());  
        
        // Step 4: 检查响应状态码
        if (response.statusCode() != 200) {  
            throw new RuntimeException("OpenAI API请求失败: " + response.statusCode() + " - " + response.body());
        }
        
        return response.body();  
    }

    /**
     * 从响应中提取内容
     * 
     * @param response API 响应（JSON 字符串）
     * @return AI 回复的内容
     * @throws Exception 如果解析失败
     */
    private String extractContent(String response) throws Exception {  
        // Step 1: 解析 JSON 响应
        JsonNode root = objectMapper.readTree(response);  
        JsonNode choices = root.get("choices");  
        
        // Step 2: 提取第一条消息的内容
        if (choices != null && choices.isArray() && choices.size() > 0) {  
            JsonNode message = choices.get(0).get("message");  
            if (message != null && message.has("content")) {  
                return message.get("content").asText();  
            }
        }
        
        return "无法解析响应";  
    }

    /**
     * 从响应中提取工具调用
     * 
     * @param response API 响应（JSON 字符串）
     * @return 工具调用对象
     * @throws Exception 如果解析失败
     */
    private ToolCall extractToolCall(String response) throws Exception {  
        // Step 1: 解析 JSON 响应
        JsonNode root = objectMapper.readTree(response);  
        JsonNode choices = root.get("choices");  
        
        // Step 2: 提取工具调用信息
        if (choices != null && choices.isArray() && choices.size() > 0) {  
            JsonNode message = choices.get(0).get("message");  
            
            if (message != null && message.has("tool_call")) {  
                JsonNode toolCall = message.get("tool_call");  
                String id = toolCall.has("id") ? toolCall.get("id").asText() : null;  
                String toolName = toolCall.has("function") ? toolCall.get("function").get("name").asText() : null;  
                String arguments = toolCall.has("function") ? toolCall.get("function").get("arguments").asText() : "{}";  
                
                // 构建 ToolCall 对象
                return ToolCall.builder()
                        .id(id)
                        .toolName(toolName)
                        .arguments(arguments)
                        .build();
            }
        }
        
        // 返回空的 ToolCall（表示没有工具调用）
        return ToolCall.builder().build();  
    }
}
```

### 4.4 VectorStoreService.java（向量存储服务）

**为什么要单独讲这个？**

因为 RAG（检索增强生成）的核心就是向量存储！当我们需要让 AI 基于"知识库"来回答问题时，必须先把文档存入向量数据库，检索时再找到最相关的文档。

**什么是向量存储？**

简单说，向量就是文档的"数字指纹"。相似的文档会有相似的向量，这样当我们搜索时，只需要找到向量相似的文档就行了。

```java
     * - title: 文档标题
     * - source: 文档来源/路径
     * - embedding: 文档的向量表示（用于相似度搜索）
     * - created_at: 创建时间
     */
    private void createTables() throws SQLException {
        String createTableSQL = """
            CREATE TABLE IF NOT EXISTS documents (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                content TEXT NOT NULL,
                title TEXT,
                source TEXT,
                embedding TEXT NOT NULL,
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
            """;
        
        try (Statement stmt = connection.createStatement()) {
            // 执行建表 SQL
            // IF NOT EXISTS 保证如果表已存在不会报错
            stmt.execute(createTableSQL);
        }
    }

    /**
     * 存储文档及其向量
     * 
     * @param content 文档内容
     * @param title 文档标题
     * @param source 文档来源
     * @param embedding 文档的向量表示
     */
    public void storeDocument(String content, String title, String source, String embedding) {
        // 使用 PreparedStatement 防止 SQL 注入
        String sql = "INSERT INTO documents (content, title, source, embedding) VALUES (?, ?, ?, ?)";
        
        try (PreparedStatement pstmt = connection.prepareStatement(sql)) {
            // 设置参数，1-indexed（第一个参数索引是 1）
            pstmt.setString(1, content);   // content -> 第一个 ?
            pstmt.setString(2, title);     // title -> 第二个 ?
            pstmt.setString(3, source);    // source -> 第三个 ?
            pstmt.setString(4, embedding); // embedding -> 第四个 ?
            pstmt.executeUpdate();          // 执行插入
            log.debug("文档存储成功: {}", title);
        } catch (SQLException e) {
            log.error("存储文档失败", e);
        }
    }

    /**
     * 语义搜索
     * 
     * 为什么叫"语义"搜索？
     * 因为我们不是搜索关键词，而是搜索语义相似的内容
     * 
     * 当前实现是简化版本（随机返回），实际生产环境应该：
     * 1. 将查询文本转为向量
     * 2. 计算余弦相似度
     * 3. 返回相似度最高的文档
     * 
     * @param queryEmbedding 查询向量（当前未使用）
     * @param topK 返回多少条结果
     * @return 匹配的文档列表
     */
    public List<Document> similaritySearch(String queryEmbedding, int topK) {
        List<Document> results = new ArrayList<>();
        
        // 简化实现：随机返回 topK 条文档
        // 实际应该使用向量相似度计算
        String sql = "SELECT id, content, title, source, embedding FROM documents ORDER BY RANDOM() LIMIT ?";
        
        try (PreparedStatement pstmt = connection.prepareStatement(sql)) {
            pstmt.setInt(1, topK);  // 设置返回数量限制
            
            try (ResultSet rs = pstmt.executeQuery()) {
                // 遍历结果集
                while (rs.next()) {
                    // 从结果集中提取数据
                    Document doc = Document.builder()
                            .id(rs.getInt("id"))
                            .content(rs.getString("content"))
                            .title(rs.getString("title"))
                            .source(rs.getString("source"))
                            .embedding(rs.getString("embedding"))
                            .build();
                    results.add(doc);
                }
            }
        } catch (SQLException e) {
            log.error("语义搜索失败", e);
        }
        
        return results;
    }

    /**
     * 获取文档总数
     * 用于显示知识库大小或分页
     */
    public int getDocumentCount() {
        String sql = "SELECT COUNT(*) FROM documents";
        
        try (Statement stmt = connection.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {
            
            // COUNT(*) 返回一个结果，第一行第一列就是计数
            if (rs.next()) {
                return rs.getInt(1);
            }
        } catch (SQLException e) {
            log.error("获取文档数量失败", e);
        }
        
        return 0;
    }

    /**
     * 清空所有文档
     * 用于重建知识库或测试
     */
    public void clearAllDocuments() {
        String sql = "DELETE FROM documents";
        
        try (Statement stmt = connection.createStatement()) {
            stmt.executeUpdate(sql);
            log.info("所有文档已清空");
        } catch (SQLException e) {
            log.error("清空文档失败", e);
        }
    }
}
```

### 4.5 RagQueryTool.java（RAG查询工具）

**这个工具是干什么的？**

RagQueryTool 是让 AI Agent 能够"查资料"的能力。当用户问"项目的核心功能是什么？"这类问题时，Agent 会自动调用这个工具去知识库查找相关文档。

**为什么需要单独一个工具？**

因为 RAG 的流程是：
1. 用户提问 -> 
2. 转成向量 -> 
3. 在向量库搜索相似文档 -> 
4. 把文档内容连同问题一起发给 LLM -> 
5. LLM 基于文档回答

这个工具就是负责第 3 步的工具！

```java
package com.example.aigent.tools;

import com.example.aigent.model.Document;
import com.example.aigent.model.Tool;
import com.example.aigent.service.VectorStoreService;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ObjectNode;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

import java.util.List;

/**
 * RAG 查询工具
 * 用于从向量存储中检索相关文档
 */
@Slf4j
@Component
public class RagQueryTool implements Tool {

    // 注入向量存储服务，用于检索文档
    private final VectorStoreService vectorStoreService;
    private final ObjectMapper objectMapper;

    // 构造器注入
    public RagQueryTool(VectorStoreService vectorStoreService, ObjectMapper objectMapper) {
        this.vectorStoreService = vectorStoreService;
        this.objectMapper = objectMapper;
    }

    @Override
    public String getName() {
        return "rag_query";
    }

    @Override
    public String getDescription() {
        return "从知识库中检索相关文档。当用户的问题需要基于已有知识回答时使用，例如：'项目的核心功能是什么？'、'如何使用这个工具？'";
    }

    @Override
    public JsonNode getParameters() {
        ObjectNode params = objectMapper.createObjectNode();
        params.put("type", "object");
        
        ObjectNode properties = objectMapper.createObjectNode();
        
        // query 参数：查询问题
        ObjectNode queryParam = objectMapper.createObjectNode();
        queryParam.put("type", "string");
        queryParam.put("description", "查询问题，用于检索相关文档");
        properties.set("query", queryParam);
        
        // top_k 参数：返回文档数量
        ObjectNode topKParam = objectMapper.createObjectNode();
        topKParam.put("type", "integer");
        topKParam.put("description", "返回的文档数量，默认3");
        topKParam.put("default", 3);  // 设置默认值
        properties.set("top_k", topKParam);
        
        params.set("properties", properties);
        // query 是必填的，top_k 是可选的
        params.putArray("required").add("query");
        
        return params;
    }

    @Override
    public String execute(JsonNode arguments) {
        try {
            // 1. 解析参数
            String query = arguments.get("query").asText();
            // 如果没有提供 top_k，使用默认值 3
            int topK = arguments.has("top_k") ? arguments.get("top_k").asInt() : 3;
            
            log.info("执行 RAG 查询: {}, 返回数量: {}", query, topK);
            
            // 2. 执行语义搜索
            // 这里调用 VectorStoreService 的 similaritySearch 方法
            List<Document> results = vectorStoreService.similaritySearch(query, topK);
            
            // 3. 构建返回结果
            StringBuilder sb = new StringBuilder();
            sb.append("{\"query\": \"").append(query).append("\", ");
            sb.append("\"results\": [");
            
            for (int i = 0; i < results.size(); i++) {
                Document doc = results.get(i);
                if (i > 0) sb.append(", ");
                sb.append("{");
                sb.append("\"title\": \"").append(doc.getTitle() != null ? doc.getTitle() : "未知标题").append("\", ");
                sb.append("\"source\": \"").append(doc.getSource() != null ? doc.getSource() : "未知来源").append("\", ");
                sb.append("\"content\": \"").append(truncateContent(doc.getContent())).append("\"");
                sb.append("}");
            }
            
            sb.append("]}");
            
            return sb.toString();
            
        } catch (Exception e) {
            log.error("RAG 查询失败", e);
            return "{\"error\": \"" + e.getMessage() + "\"}";
        }
    }

    /**
     * 截断过长的内容
     * 
     * 为什么需要截断？
     * - LLM 的输入有长度限制（Token 限制）
     * - 返回太多内容也没必要，选取最相关的部分即可
     * - 避免 JSON 过长导致解析问题
     */
    private String truncateContent(String content) {
        if (content == null) return "";
        // 转义双引号和换行符，防止 JSON 格式错误
        String escaped = content.replace("\"", "\\\"")
                                .replace("\n", "\\n")
                                .replace("\r", "\\r");
        // 限制长度 500 字符
        return escaped.length() > 500 ? escaped.substring(0, 500) + "..." : escaped;
    }
}
```

### 4.6 DocumentLoaderTool.java（文档加载工具）

**这个工具是干什么的？**

DocLoaderTool 是用来"上传资料到知识库"的。用户的文档（txt、md、json）通过这个工具存入向量数据库，之后 RAG 查询才能查到。

**为什么需要这个工具？**

因为知识库不会凭空产生内容！必须先把文档加载进去。想象成一个图书馆：先要有书（DocumentLoader），才能借书（RagQuery）。

```java
package com.example.aigent.tools;

/**
 * 文档加载工具
 * 用于将文档加载到向量存储中，支持文本文件和 Markdown 文件
 */
@Slf4j
@Component
public class DocumentLoaderTool implements Tool {

    private final ObjectMapper objectMapper;

    @Override
    public String getName() {
        return "load_document";
    }

    @Override
    public String getDescription() {

        ObjectNode pathParam = objectMapper.createObjectNode();
        pathParam.put("type", "string");
        pathParam.put("description", "要加载的文件路径");
        properties.set("file_path", pathParam);
        
        // title：文档标题（可选）
        ObjectNode titleParam = objectMapper.createObjectNode();
        titleParam.put("type", "string");
        titleParam.put("description", "文档标题（可选，默认使用文件名）");
        properties.set("title", titleParam);
        
        params.set("properties", properties);
        params.putArray("required").add("file_path");
        
        return params;
    }

    @Override
    public String execute(JsonNode arguments) {
        try {
            // 1. 获取参数
            String filePath = arguments.get("file_path").asText();
            // 如果没有提供 title，则为 null
            String title = arguments.has("title") ? arguments.get("title").asText() : null;
            
            log.info("加载文档: {}", filePath);
            
            // 2. 读取文件内容
            Path path = Paths.get(filePath);
            if (!Files.exists(path)) {
                return "{\"error\": \"文件不存在: " + filePath + "\"}";
            }
            
            // 读取整个文件内容
            String content = Files.readString(path);
            
            // 3. 如果没有指定标题，使用文件名
            if (title == null || title.isEmpty()) {
                title = path.getFileName().toString();
            }
            
            // 4. 生成向量
            // 注意：这里是简化实现，实际应该调用 Embedding API（如 OpenAI Embeddings）
            String embedding = generateMockEmbedding(content);
            
            // 5. 存储到向量数据库
            vectorStoreService.storeDocument(content, title, filePath, embedding);
            
            // 6. 获取更新后的文档总数
            int docCount = vectorStoreService.getDocumentCount();
            
            return "{\"status\": \"success\", \"message\": \"文档加载成功\", " +
                   "\"title\": \"" + title + "\", " +
                   "\"content_length\": " + content.length() + ", " +
                   "\"total_documents\": " + docCount + "}";
            
        } catch (IOException e) {
            log.error("加载文档失败", e);
            return "{\"error\": \"加载文档失败: " + e.getMessage() + "\"}";
        }
    }

    /**
     * 生成模拟向量
     * 
     * 为什么是"模拟"的？
     * 因为真正的向量需要调用 OpenAI Embedding API，
     * 为了让项目能够独立运行，这里用简单的哈希生成模拟向量
     * 
     * 实际生产环境应该：
     * 1. 调用 OpenAI Embeddings API
     * 2. 传入文档内容
     * 3. 获取 1536 维的向量（text-embedding-3-small）或 3072 维（text-embedding-3-large）
     */
    private String generateMockEmbedding(String content) {
        // 生成一个简单的模拟向量（10 维）
        int hash = content.hashCode();
        StringBuilder sb = new StringBuilder("[");
        for (int i = 0; i < 10; i++) {
            if (i > 0) sb.append(", ");
            // 用哈希值生成 0-1 之间的数
            sb.append((hash + i * 1000) % 1000 / 1000.0);
        }
        sb.append("]");
        return sb.toString();
    }
}
```

### 4.7 MultiAgentCoordinator.java（多智能体协调服务）

**什么是 MCP？**

MCP = Multi-Agent Collaboration Protocol（多智能体协作协议）。就是让多个专业智能体协同工作，而不是一个"全能"智能体。

**为什么需要多个智能体？**

就像一个公司有不同部门：销售部、技术部、财务部...
- 搜索Agent：专门负责搜索
- 文档Agent：专门处理文档
- 数学Agent：专门做计算

这样每个 Agent 都能在自己的领域做得更专业！

```java
package com.example.aigent.service;

import lombok.AllArgsConstructor;
import lombok.Builder;
import lombok.Data;
import lombok.NoArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

import jakarta.annotation.PostConstruct;
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;

/**
 * MCP（多智能体协作）协调服务
 * 负责管理多个智能体之间的协作和任务分发
 */
@Slf4j
@Service
public class MultiAgentCoordinator {

    /**
     * 可用的智能体列表
     * 为什么用 Map？
     * - 方便通过 ID 快速查找智能体
     * - 并发安全（ConcurrentHashMap）
     */
    private final Map<String, AgentInfo> agents = new ConcurrentHashMap<>();

    /**
     * 正在进行的协作任务
     * 用于跟踪多智能体协作的状态
     */
    private final Map<String, CollaborationTask> tasks = new ConcurrentHashMap<>();

    /**
     * 初始化方法
     * 
     * 为什么用 @PostConstruct？
     * 确保在服务完全初始化后才注册内置智能体
     */
    @PostConstruct
    public void init() {
        // 注册内置智能体
        
        // 1. 搜索专家
        registerAgent(AgentInfo.builder()
                .id("search_agent")
                .name("搜索专家")
                .description("擅长网络搜索和信息收集")
                // 这个 Agent 能做的任务类型
                .capabilities(List.of("web_search", "fetch_webpage"))
                .build());

        // 2. 文档专家
        registerAgent(AgentInfo.builder()
                .id("document_agent")
                .name("文档专家")
                .description("擅长文档处理和知识检索")
                .capabilities(List.of("read_file", "list_directory", "rag_query"))
                .build());

        // 3. 任务专家
        registerAgent(AgentInfo.builder()
                .id("todo_agent")
                .name("任务专家")
                .description("擅长任务管理和待办事项")
                .capabilities(List.of("manage_todo"))
                .build());

        // 4. 数学专家
        registerAgent(AgentInfo.builder()
                .id("math_agent")
                .name("数学专家")
                .description("擅长数学计算")
                .capabilities(List.of("calculator"))
                .build());

        log.info("MCP 协调服务初始化完成，注册了 {} 个智能体", agents.size());
    }

    /**
     * 注册智能体
     * @param agent 智能体信息
     */
    public void registerAgent(AgentInfo agent) {
        agents.put(agent.getId(), agent);
        log.info("智能体已注册: {}", agent.getName());
    }

    /**
     * 获取所有智能体信息
     */
    public List<AgentInfo> getAgents() {
        return new ArrayList<>(agents.values());
    }

    /**
     * 根据任务描述选择最合适的智能体
     * 
     * 为什么需要这个方法？
     * 因为需要根据任务类型自动分配给最专业的 Agent
     * 
     * @param taskDescription 任务描述
     * @return 最合适的智能体
     */
    public AgentInfo selectAgent(String taskDescription) {
        // 简单的关键词匹配逻辑
        // 实际生产环境可以用 LLM 来做更智能的任务分配
        String lowerDesc = taskDescription.toLowerCase();
        
        // 根据关键词判断任务类型
        if (lowerDesc.contains("搜索") || lowerDesc.contains("网络") || lowerDesc.contains("新闻")) {
            return agents.get("search_agent");
        } else if (lowerDesc.contains("文档") || lowerDesc.contains("文件") || lowerDesc.contains("知识")) {
            return agents.get("document_agent");
        } else if (lowerDesc.contains("待办") || lowerDesc.contains("任务") || lowerDesc.contains("计划")) {
            return agents.get("todo_agent");
        } else if (lowerDesc.contains("计算") || lowerDesc.contains("数学") || lowerDesc.contains("公式")) {
            return agents.get("math_agent");
        }
        
        // 默认返回文档专家（最常用的）
        return agents.get("document_agent");
    }

    /**
     * 创建协作任务
     * @param description 任务描述
     * @param requester 请求者
     * @return 任务 ID
     */
    public String createTask(String description, String requester) {
        // 生成唯一任务 ID
        String taskId = "task-" + UUID.randomUUID().toString().substring(0, 8);
        
        // 创建任务对象
        CollaborationTask task = CollaborationTask.builder()
                .id(taskId)
                .description(description)
                .requester(requester)
                .status("created")
                .createdAt(new Date())
                .build();
        
        tasks.put(taskId, task);
        
        // 自动选择合适的智能体
        AgentInfo agent = selectAgent(description);
        if (agent != null) {
            task.setAssignedAgent(agent.getId());
            task.setStatus("assigned");
            log.info("任务已分配给智能体 {}: {}", agent.getName(), taskId);
        }
        
        return taskId;
    }

    /**
     * 获取任务状态
     */
    public CollaborationTask getTask(String taskId) {
        return tasks.get(taskId);
    }

    /**
     * 更新任务状态
     */
    public void updateTaskStatus(String taskId, String status, String result) {
        CollaborationTask task = tasks.get(taskId);
        if (task != null) {
            task.setStatus(status);
            task.setResult(result);
            task.setUpdatedAt(new Date());
            log.info("任务状态更新: {} -> {}", taskId, status);
        }
    }

    /**
     * 获取所有任务列表
     */
    public List<CollaborationTask> getAllTasks() {
        return new ArrayList<>(tasks.values());
    }

    /**
     * 内部类：智能体信息
     */
    @Data
    @Builder
    @NoArgsConstructor
    @AllArgsConstructor
    public static class AgentInfo {
        private String id;
        private String name;
        private String description;
        private List<String> capabilities;  // 该智能体能处理的任务类型
    }

    /**
     * 内部类：协作任务
     */
    @Data
    @Builder
    @NoArgsConstructor
    @AllArgsConstructor
    public static class CollaborationTask {
        private String id;
        private String description;
        private String requester;
        private String assignedAgent;  // 分配的智能体 ID
        private String status;         // created, assigned, in_progress, completed, failed
        private String result;         // 任务结果
        private Date createdAt;
        private Date updatedAt;
    }
}
```

### 4.8 FetchFromWebTool.java（网页抓取工具）

**这个工具是干什么的？**

FetchFromWebTool 用于抓取网页内容，提取标题、正文和链接。这是 RAG 的补充：当知识库里没有的信息时，可以去网上抓取。

```java

/**

        this.httpClient = HttpClient.newHttpClient();
    }

    @Override
    public String getName() {
        return "fetch_webpage";
    }

    @Override
    public String getDescription() {
        return "获取网页内容，提取标题、正文和链接。参数：url（网页URL）";
    }

    @Override
    public JsonNode getParameters() {
        ObjectNode params = objectMapper.createObjectNode();
        params.put("type", "object");
        
        ObjectNode properties = objectMapper.createObjectNode();
        
        // url 参数：网页地址（必填）
        ObjectNode urlProp = objectMapper.createObjectNode();
        urlProp.put("type", "string");
        urlProp.put("description", "网页URL");
        properties.set("url", urlProp);
        
        params.set("properties", properties);
        
        return params;
    }

    @Override
    public String execute(JsonNode arguments) {
        // 1. 获取 URL 参数
        String url = arguments.has("url") ? arguments.get("url").asText() : "";
        
        if (url.isEmpty()) {
            return "{\"error\": \"URL不能为空\"}";
        }
        
        try {
            // 2. 发送 HTTP GET 请求
            HttpRequest request = HttpRequest.newBuilder()
                    .uri(URI.create(url))
                    .GET()
                    .build();
            
            HttpResponse<String> response = httpClient.send(request, 
                    HttpResponse.BodyHandlers.ofString());
            
            // 3. 解析 HTML
            // Jsoup.parse() 可以解析任意 HTML 字符串
            Document doc = Jsoup.parse(response.body(), url);
            
            // 4. 提取内容
            String title = doc.title();  // <title> 标签
            String body = doc.body().text();  // 正文文本
            
            // 如果正文过长，截断
            if (body.length() > 2000) {
                body = body.substring(0, 2000) + "...";
            }
            
            // 5. 提取链接
            Elements links = doc.select("a[href]");  // 选择所有带 href 的 <a> 标签
            StringBuilder linksStr = new StringBuilder();
            links.stream().limit(10).forEach(link -> {
                // abs:href 获取绝对 URL
                String href = link.attr("abs:href");
                String text = link.text();
                linksStr.append("- [").append(text).append("](").append(href).append(")\n");
            });
            
            // 6. 构建返回结果
            ObjectNode result = objectMapper.createObjectNode();
            result.put("url", url);
            result.put("title", title);
            result.put("content", body);
            result.put("links", linksStr.toString());
            result.put("status_code", response.statusCode());
            
            return objectMapper.writeValueAsString(result);
            
        } catch (Exception e) {
            log.error("获取网页失败: {}", e.getMessage());
            return "{\"error\": \"获取网页失败: " + e.getMessage() + "\"}";
        }
    }
}
```

### 5.1 ReActAgent.java

```java
package com.example.aigent.agent;

import com.example.aigent.model.*;
import com.example.aigent.service.ConversationHistory;
import com.example.aigent.service.OpenAIService;
import com.example.aigent.service.ToolRegistry;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import java.util.ArrayList;
import java.util.List;

@Slf4j
@Component
public class ReActAgent {

    private final OpenAIService openAIService;
    private final ToolRegistry toolRegistry;
    private final ConversationHistory conversationHistory;
    private final ObjectMapper objectMapper;
    
    @Value("${app.agent.max-tool-calls:5}")
    private int maxToolCalls;

    public ReActAgent(OpenAIService openAIService, 
                      ToolRegistry toolRegistry,
                      ConversationHistory conversationHistory,
                      ObjectMapper objectMapper) {
        this.openAIService = openAIService;
        this.toolRegistry = toolRegistry;
        this.conversationHistory = conversationHistory;
        this.objectMapper = objectMapper;
    }

    private static final String REACT_SYSTEM_PROMPT = """
        你是一个AI Agent，具备使用工具的能力。请按照以下ReAct框架进行思考和行动：
        
        思考过程格式：
        1. 分析用户的问题或请求
        2. 决定是否需要调用工具
        3. 如果需要，选择合适的工具并执行
        4. 根据工具返回结果进行总结
        """;

    public AgentResponse execute(String conversationId, String userInput) {
        long startTime = System.currentTimeMillis();
        List<String> thoughts = new ArrayList<>();
        List<String> toolsUsed = new ArrayList<>();
        
        try {
            if (conversationId == null || conversationId.isEmpty()) {
                conversationId = conversationHistory.createConversation();
                log.info("创建新对话: {}", conversationId);
            }
            
            if (!conversationHistory.exists(conversationId)) {
                conversationHistory.createConversation();
            }
            
            conversationHistory.addMessage(conversationId, Message.user(userInput));
            thoughts.add("用户输入: " + userInput);
            
            List<Message> messages = buildMessages(conversationId);
            
            int toolCallCount = 0;
            boolean continueLoop = true;
            
            while (continueLoop && toolCallCount < maxToolCalls) {
                ToolCall toolCall = openAIService.chatCompletionWithTools(messages, 
                        toolRegistry.getToolsAsJsonSchema());
                
                if (toolCall.isValid()) {
                    thoughts.add("思考: 需要调用工具 " + toolCall.getToolName());
                    log.info("工具调用: {} ({})", toolCall.getToolName(), toolCall.getArguments());
                    
                    String toolResult = executeTool(toolCall);
                    toolsUsed.add(toolCall.getToolName());
                    thoughts.add("工具返回: " + truncate(toolResult, 200));
                    
                    messages.add(Message.assistant("调用工具: " + toolCall.getToolName()));
                    messages.add(Message.tool(toolCall.getToolName(), toolResult, toolCall.getId()));
                    conversationHistory.addMessage(conversationId, 
                            Message.assistant("调用工具: " + toolCall.getToolName()));
                    conversationHistory.addMessage(conversationId, 
                            Message.tool(toolCall.getToolName(), toolResult, toolCall.getId()));
                    
                    toolCallCount++;
                } else {
                    continueLoop = false;
                }
            }
            
            String finalAnswer = openAIService.chatCompletion(messages);
            thoughts.add("总结回答: " + truncate(finalAnswer, 200));
            
            conversationHistory.addMessage(conversationId, Message.assistant(finalAnswer));
            
            long responseTime = System.currentTimeMillis() - startTime;
            
            return AgentResponse.success(conversationId, finalAnswer, thoughts, toolsUsed, responseTime);
            
        } catch (Exception e) {
            log.error("Agent执行失败: {}", e.getMessage(), e);
            return AgentResponse.error(e.getMessage());
        }
    }

    private List<Message> buildMessages(String conversationId) {
        List<Message> messages = new ArrayList<>();
        
        String toolDescriptions = String.join("\n", toolRegistry.getToolDescriptions());
        String systemPrompt = REACT_SYSTEM_PROMPT.replace("{tool_descriptions}", toolDescriptions);
        
        messages.add(Message.system(systemPrompt));
        messages.addAll(conversationHistory.getMessages(conversationId));
        
        return messages;
    }

    private String executeTool(ToolCall toolCall) {
        Tool tool = toolRegistry.getTool(toolCall.getToolName());
        
        if (tool == null) {
            return "{\"error\": \"未知工具: " + toolCall.getToolName() + "\"}";
        }
        
        try {
            JsonNode arguments = objectMapper.readTree(toolCall.getArguments());
            return tool.execute(arguments);
        } catch (Exception e) {
            log.error("工具执行失败: {}", e.getMessage());
            return "{\"error\": \"工具执行失败: " + e.getMessage() + "\"}";
        }
    }

    private String truncate(String text, int maxLength) {
        if (text == null) return "";
        return text.length() > maxLength ? text.substring(0, maxLength) + "..." : text;
    }
}
```

```javascript
let conversationId = null;

async function sendMessage() {
    const input = document.getElementById('messageInput');
    const message = input.value.trim();
    
    if (!message) return;
    
    appendMessage('user', message);
    input.value = '';
    
    const loadingEl = appendMessage('assistant', '思考中...');
    
    try {
        const response = await fetch('/api/agent/chat', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
                message: message,
                conversationId: conversationId
            })
        });
        
        const data = await response.json();
        
        conversationId = data.conversationId;
        
        loadingEl.innerHTML = formatResponse(data);
        
    } catch (error) {
        loadingEl.innerHTML = `<p style="color: red;">错误: ${error.message}</p>`;
    }
}

function appendMessage(role, content) {
    const container = document.getElementById('chatContainer');
    const div = document.createElement('div');
    div.className = `message ${role}-message`;
    div.innerHTML = `<p>${content}</p>`;
    container.appendChild(div);
    container.scrollTop = container.scrollHeight;
    return div;
}

function formatResponse(data) {
    let html = `<p><strong>回答：</strong>${data.answer}</p>`;
    
    if (data.toolsUsed && data.toolsUsed.length > 0) {
        html += `<p><strong>使用的工具：</strong>${data.toolsUsed.join(', ')}</p>`;
    }
    
    html += `<p><strong>响应时间：</strong>${data.responseTimeMs}ms</p>`;
    
    return html;
}

document.getElementById('messageInput').addEventListener('keypress', function(e) {
    if (e.key === 'Enter') {
        sendMessage();
    }
});
```
