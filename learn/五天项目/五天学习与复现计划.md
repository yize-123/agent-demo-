### 📚 理论学习

#### 1.1 什么是AI Agent

**定义**：AI Agent（人工智能代理）是一种能够感知环境、自主决策、执行动作的智能系统。

```
┌─────────────────────────────────────────────────────────────┐
│                      AI Agent 工作循环                       │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│    感知 ──▶ 推理 ──▶ 行动 ──▶ 学习                          │
│      ↑                                       │              │
│      └───────────────────────────────────────┘              │
│                                                              │
│    感知: 接收用户输入、工具返回结果                           │
│    推理: 分析问题、制定计划、决定行动                          │
│    行动: 调用工具、执行操作                                   │
│    学习: 记忆交互、反思改进                                   │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

#### 1.2 AI Agent vs 传统AI

| 对比项 | 传统AI（如ChatGPT） | AI Agent |
|--------|---------------------|----------|
| 交互方式 | 单次请求-响应 | 多轮循环交互 |
| 工具能力 | 无 | 有（可调用外部工具） |
| 任务范围 | 单一任务 | 多步骤复杂任务 |
| 自主程度 | 低（被动响应） | 高（主动规划） |

### 📚 理论学习

#### 3.1 ReAct框架核心思想

**ReAct = Reasoning + Acting**

核心是**交错进行推理和行动**，让LLM能够动态控制推理过程。

```
┌─────────────────────────────────────────────────────────────┐
│                    ReAct 循环流程                           │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│    ┌──────────────────────────────────────────┐             │
│    │ 1. Thought: 分析问题，决定是否需要工具     │             │
│    └─────────────────────┬────────────────────┘             │
│                          ▼                                   │
│    ┌──────────────────────────────────────────┐             │
│    │ 2. Action: 调用工具（如web_search）        │             │
│    └─────────────────────┬────────────────────┘             │
│                          ▼                                   │
│    ┌──────────────────────────────────────────┐             │
│    │ 3. Observation: 获取工具返回结果           │             │
│    └─────────────────────┬────────────────────┘             │
│                          ▼                                   │
│              ┌───────────────────────┐                       │
│              │ 继续循环 or 结束？     │                       │
│              └───────┬───────────────┘                       │
│                      │                                       │
│           ┌──────────┴──────────┐                           │
│           ▼                      ▼                          │
│      继续循环                 生成回答                       │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

#### 3.2 ReAct vs 其他框架

| 框架 | 特点 | 项目适用性 |
|------|------|-----------|
| ReAct | 推理+行动交替 | ✅ 本项目采用 |
| CoT | 只推理不行动 | ❌ 无法调用工具 |
| ToT | 树形搜索探索 | ❌ 计算成本高 |

### 🔍 项目代码解析

#### 3.3 ReActAgent核心实现

阅读 [ReActAgent.java](file:///d:\HuaweiMoveData\Users\C\Desktop\Star-Prograss\demo-springAi\src\main\java\com\example\aigent\agent\ReActAgent.java)：

**ReAct循环核心代码**（第68-95行）：

```java
int toolCallCount = 0;
boolean continueLoop = true;

while (continueLoop && toolCallCount < maxToolCalls) {
    // 1. 调用LLM，获取工具调用指令
    ToolCall toolCall = openAIService.chatCompletionWithTools(
        messages,
        toolRegistry.getToolsAsJsonSchema()
    );

    // 2. 无需工具调用，退出循环
    if (!toolCall.isValid()) {
        continueLoop = false;
        break;
    }

    // 3. 添加工具调用消息
    messages.add(Message.assistant("调用工具: " + toolCall.getToolName()));

    // 4. 执行工具
    String toolResult = executeTool(toolCall);

    // 5. 添加工具结果消息
    messages.add(Message.tool(
        toolCall.getToolName(),
        toolResult,
        toolCall.getId()
    ));

    toolCallCount++;
}
```

**关键变量**：

| 变量 | 作用 | 可配置 |
|------|------|--------|
| maxToolCalls | 最大工具调用次数，防止无限循环 | ✅ app.agent.max-tool-calls |
| toolCallCount | 当前调用次数计数器 | - |

#### 3.4 工具执行流程

```java
private String executeTool(ToolCall toolCall) {
    // 1. 根据名称获取工具
    Tool tool = toolRegistry.getTool(toolCall.getToolName());

    // 2. 解析参数
    JsonNode args = objectMapper.readTree(toolCall.getArguments());

    // 3. 执行工具
    return tool.execute(args);
}
```

#### 4.1 Tool接口规范

```java
public interface Tool {
    String getName();              // ① 工具唯一名称
    String getDescription();       // ② 供LLM理解用途
    JsonNode getParameters();      // ③ 参数Schema定义
    String execute(JsonNode arguments);  // ④ 执行逻辑
}
```

**设计意图**：

| 方法 | 作用 | 被谁使用 |
|------|------|---------|
| getName() | 唯一标识工具 | ToolRegistry、LLM |
| getDescription() | 帮助LLM选择工具 | OpenAI API |
| getParameters() | 定义参数结构 | OpenAI API |
| execute() | 执行具体功能 | ReActAgent |

#### 4.2 工具注册机制

```
Spring容器启动
     │
     ▼
扫描所有 @Component 且实现 Tool 接口的类
     │
     ▼
自动注入到 ToolRegistry 构造函数
     │
     ▼
tools.put(tool.getName(), tool)
     │
     ▼
可供Agent调用
```

**优势**：
- 自动发现，无需手动注册
- 新增工具只需实现接口
- 符合开闭原则

#### 任务4.1：创建计算器工具

**目标**：创建一个支持基本运算的计算器工具

**步骤1**：创建CalculatorTool.java

```java
@Component
public class CalculatorTool implements Tool {

    @Override
    public String getName() {
        return "calculator";
    }

    @Override
    public String getDescription() {
        return "执行数学计算，支持加减乘除运算。参数：expression（数学表达式）";
    }

    @Override
    public JsonNode getParameters() {
        ObjectMapper mapper = new ObjectMapper();
        ObjectNode params = mapper.createObjectNode();
        params.put("type", "object");

        ObjectNode properties = mapper.createObjectNode();
        ObjectNode expr = mapper.createObjectNode();
        expr.put("type", "string");
        expr.put("description", "数学表达式，如 2+3*4");
        properties.set("expression", expr);

        params.set("properties", properties);
        params.putArray("required").add("expression");
        return params;
    }

    @Override
    public String execute(JsonNode arguments) {
        String expr = arguments.get("expression").asText();
        try {
            // 使用ScriptEngine执行表达式
            ScriptEngine engine = new ScriptEngineManager()
                .getEngineByName("JavaScript");
            Object result = engine.eval(expr);
            return "{\"result\": " + result + "}";
        } catch (Exception e) {
            return "{\"error\": \"计算错误: " + e.getMessage() + "\"}";
        }
    }
}
```
