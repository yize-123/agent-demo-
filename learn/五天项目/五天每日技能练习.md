### 任务1：添加一个「计算器工具」

**背景**：你学了5个工具的实现方式，现在要自己实现一个计算器工具。

**功能**：支持加减乘除运算

**添加步骤**：

1. 在 `src/main/java/com/example/aigent/tools/` 目录下新建 `CalculatorTool.java`

```java
package com.example.aigent.tools;

import com.example.aigent.model.Tool;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ObjectNode;
import org.springframework.stereotype.Component;

@Component
public class CalculatorTool implements Tool {

    @Override
    public String getName() {
        return "calculator";
    }

    @Override
    public String getDescription() {
        return "执行数学计算，支持加减乘除运算。输入一个数学表达式，返回计算结果";
    }

    @Override
    public JsonNode getParameters() {
        ObjectMapper mapper = new ObjectMapper();
        ObjectNode params = mapper.createObjectNode();
        params.put("type", "object");
        ObjectNode properties = mapper.createObjectNode();
        ObjectNode expr = mapper.createObjectNode();
        expr.put("type", "string");
        expr.put("description", "数学表达式，如 2+3*4");
        properties.set("expression", expr);
        params.set("properties", properties);
        params.putArray("required").add("expression");
        return params;
    }

    @Override
    public String execute(JsonNode arguments) {
        try {
            String expr = arguments.get("expression").asText();
            // 使用 JavaScript 引擎计算表达式
            javax.script.ScriptEngine engine =
                new javax.script.ScriptEngineManager()
                    .getEngineByName("JavaScript");
            Object result = engine.eval(expr);
            return "{\"result\": " + result + "}";
        } catch (Exception e) {
            return "{\"error\": \"计算错误: " + e.getMessage() + "\"}";
        }
    }
}
```

2. 重新编译观察日志，应该看到 `工具已注册: calculator`

3. 测试：问"计算 25 + 37 等于多少"

**完成后回答**：
- CalculatorTool 实现了哪个接口？
- 4个必须实现的方法分别是什么？
- parameters 方法返回的 JSON 结构有什么作用？

### 任务2：添加一个「随机选择工具」

**功能**：输入几个选项，随机返回一个

**添加步骤**：

1. 新建 `RandomChoiceTool.java`

```java
package com.example.aigent.tools;

import com.example.aigent.model.Tool;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ObjectNode;
import org.springframework.stereotype.Component;

import java.util.Arrays;
import java.util.concurrent.ThreadLocalRandom;

@Component
public class RandomChoiceTool implements Tool {

    @Override
    public String getName() {
        return "random_choice";
    }

    @Override
    public String getDescription() {
        return "从多个选项中随机选择一个。例如：随机选择午饭吃什么";
    }

    @Override
    public JsonNode getParameters() {
        ObjectMapper mapper = new ObjectMapper();
        ObjectNode params = mapper.createObjectNode();
        params.put("type", "object");
        ObjectNode properties = mapper.createObjectNode();
        ObjectNode opts = mapper.createObjectNode();
        opts.put("type", "string");
        opts.put("description", "用逗号分隔的选项，如：火锅,烧烤,寿司");
        properties.set("options", opts);
        params.set("properties", properties);
        params.putArray("required").add("options");
        return params;
    }

    @Override
    public String execute(JsonNode arguments) {
        try {
            String options = arguments.get("options").asText();
            String[] choices = options.split(",");
            int randomIndex = ThreadLocalRandom.current().nextInt(choices.length);
            String selected = choices[randomIndex].trim();
            return "{\"selected\": \"" + selected + "\", \"from\": " + choices.length + "}";
        } catch (Exception e) {
            return "{\"error\": \"" + e.getMessage() + "\"}";
        }
    }
}
```

2. 测试：问"帮我随机选一个午饭吃啥，有火锅、烧烤、寿司"

```javascript
function addMessage(role, content, thoughts) {
    const container = document.getElementById('chatContainer');
    const welcome = container.querySelector('.welcome-message');
    if (welcome) {
        welcome.remove();
    }

    const messageDiv = document.createElement('div');
    messageDiv.className = 'message ' + role;

    let fullContent = content;
    if (role === 'assistant' && thoughts && thoughts.length > 0) {
        fullContent = '<div class="thoughts">思考过程：</div>' + content;
    }

    messageDiv.innerHTML = `<div class="message-content">${fullContent.replace(/\n/g, '<br>')}</div>`;
    container.appendChild(messageDiv);
    container.scrollTop = container.scrollHeight;
}

function showLoading() {
    const container = document.getElementById('chatContainer');
    const loadingDiv = document.createElement('div');
    loadingDiv.className = 'message assistant';
    loadingDiv.id = 'loading';
    loadingDiv.innerHTML = '<div class="message-content">思考中...</div>';
    container.appendChild(loadingDiv);
    container.scrollTop = container.scrollHeight;

function hideLoading() {
    const loading = document.getElementById('loading');
    if (loading) {
        loading.remove();
    }
}
```

2. 修改 `sendMessage` 函数

```javascript
async function sendMessage() {
    const input = document.getElementById('userInput');
    const message = input.value.trim();
    if (!message) return;

    input.value = '';
    addMessage('user', message);
    showLoading();

    try {
        const response = await fetch('/api/agent/chat', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
                message: message,
                conversationId: currentConversationId
            })
        });

        hideLoading();
        const data = await response.json();
        // ... 后续代码
    } catch (error) {
        hideLoading();
        addMessage('assistant', '抱歉，发生了错误: ' + error.message);
    }
}
```
