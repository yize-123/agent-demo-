## 1. 快速启动

### 步骤1: 设置环境变量

```bash
# Windows PowerShell
$env:OPENAI_API_KEY="your-api-key-here"

# 验证设置
echo $env:OPENAI_API_KEY
```

### 步骤2: 启动服务

```bash
# 进入项目目录
cd demo-springAi

# 启动应用
mvn spring-boot:run
```

### 步骤3: 验证服务

```bash
# 健康检查
curl http://localhost:8080/api/agent/health

# 预期输出:
# {"status":"UP","service":"AI Agent Demo","tool_count":5,"conversation_count":0}
```

### 步骤4: 访问前端页面

打开浏览器访问:  
**http://localhost:8080/index.html**

## 2. 核心概念

### 2.1 AI Agent

AI Agent是一个能够：
- **感知**：理解用户输入
- **推理**：分析问题，决定如何行动
- **行动**：调用工具获取信息
- **总结**：基于结果生成回答

### 2.2 ReAct框架

ReAct = Reasoning + Acting（推理+行动）

```
思考 → 决定是否调用工具 → 执行工具 → 获取结果 → 总结回答
```

### 2.3 工具系统

项目包含5个内置工具：

| 工具名称 | 功能 |
|----------|------|
| web_search | 网络搜索 |
| fetch_webpage | 网页抓取 |
| read_file | 文件读取 |
| list_directory | 目录列表 |
| manage_todo | 待办管理 |

## 3. API示例

### 3.1 发送消息

```bash
curl -X POST http://localhost:8080/api/agent/chat \
  -H "Content-Type: application/json" \
  -d '{
    "conversationId": "",
    "message": "帮我搜索AI Agent最新技术"
  }'
```

### 3.2 多轮对话

```bash
# 第一次请求（获取conversationId）
curl -X POST http://localhost:8080/api/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "你好"}'

# 第二次请求（使用返回的conversationId）
curl -X POST http://localhost:8080/api/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"conversationId": "uuid-string", "message": "今天天气怎么样？"}'
```

### 3.3 获取工具列表

```bash
curl http://localhost:8080/api/agent/tools
```

### 3.4 获取对话列表

```bash
curl http://localhost:8080/api/agent/conversations
```

## 4. 工具说明

### 4.1 web_search

**功能**: 搜索网络获取实时信息

**使用场景**: 需要最新数据时

```bash
curl -X POST http://localhost:8080/api/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "今天的新闻热点是什么？"}'
```

### 4.2 read_file

**功能**: 读取文件内容

**使用场景**: 需要分析文档时

```bash
curl -X POST http://localhost:8080/api/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "帮我读取README.md文件"}'
```

### 4.3 list_directory

**功能**: 列出目录内容

**使用场景**: 需要浏览文件系统时

```bash
curl -X POST http://localhost:8080/api/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "列出当前目录"}'
```

### 4.4 manage_todo

**功能**: 管理待办事项

**使用场景**: 需要管理任务时

```bash
# 添加待办
curl -X POST http://localhost:8080/api/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "添加待办：学习AI Agent"}'

# 查看待办
curl -X POST http://localhost:8080/api/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "列出所有待办"}'
```

## 5. 常见操作

### 5.1 清空对话

```bash
# 使用前端页面的"清空"按钮
# 或删除对话
curl -X DELETE http://localhost:8080/api/agent/conversations/{id}
```

### 5.2 切换主题

点击页面右上角的主题切换按钮，支持亮色/暗色模式。

### 5.3 使用快捷按钮

前端页面提供快捷操作按钮：
- 搜索AI技术
- 浏览目录
- 添加待办

### 5.4 查看思考过程

在对话响应中，点击"思考过程"可以展开查看AI的推理步骤。
